It expires old proposals and revalidates before execution. |\n| Actual outcome | [`transaction_executor.py`](app/services/transaction_executor.py) supplies `SUCCESS`, `FAILED`, or `PENDING`. Failed transfers leave the balance unchanged; pending transfers hold funds. |\n| Visitor isolation | [`hosted_store.py`](app/hosted_store.py) keeps one Redis snapshot per visitor with a 120-second lease, compare-owner commit, and 24-hour inactivity expiry. |\n| Bounded execution | [`agent.py`](app/agent.py) applies Redis user/model admission and tool limits. The hosted runner bounds each turn to 75 seconds and eight model calls. |\n| Request boundary | [`web.py`](app/web.py) validates declared lengths and caps actual streamed POST bodies at 12,000 bytes before parsing or calling a handler. Lua updates perform insertion and eviction atomically. |\n| Cache invalidation | [`resources.py`](phase2_retrieval/resources.py) derives the namespace from PDF, index and document-text/metadata hashes, embedding and answer models, threshold, and response-policy version. Changed citation metadata or the strict completion policy selects a new namespace, preventing stale cached answers from bypassing the updated context. |\n| Admission before paid work | [`backend.py`](phase2_retrieval/backend.py) admits clients before lookup and uses a separate shared gate before query embedding. Exact hits avoid provider calls; semantic hits still require a query embedding. |\n| Safe index loading | The loader checks corpus/index/metadata hashes and embedding dimensions, then reads FAISS plus JSON metadata rather than deserializing a pickle. |\n| Answer boundary | Non-refusal answers require page labels present in the retrieved passages. Only a completed `stop` generation can enter the cache; truncated, filtered, tool-call and unknown completion states return explicit errors. |\n\nDefault cache settings are 256 entries and a 24-hour TTL per namespace. Semantic matching uses a cosine-distance threshold, so similar wording can reuse an answer. Citation-label checks validate page membership, not factual entailment.\n\nThe local Valkey adapter uses the same bounded hash/Lua contract as the Redis adapter, with a cosine scan of the configured entry limit. It reuses the query vector supplied by the handler, supports exact lookups before embedding, and does not require a vector-search module. This is a small bounded cache, not an indexed ANN service.     "content": "# ADR 0001: Canonical Express service and durable effects\n\nStatus: accepted for implementation, cloud operation pending.\n\nThe five-framework lab needs a comparable contract while production hardening requires one operational target. Express is canonical. Comparison backends advertise their actual capabilities; missing Go routes are not silently treated as passing. The historical vertical exercise stays separate from the horizontal profile.\n\nMongo is the durable authority for sessions, idempotency receipts, ingestion jobs and outbox. Majority transactions connect acknowledgement to persisted work. SQS provides at-least-once delivery; leased workers and unique transactional effects tolerate duplicates. Redis is rebuildable public-catalog acceleration. Private authorization never depends on positive Redis cache entries.\n\nECS/Atlas are the cloud reference because separate tasks, managed data and protected digest promotion meet the scope without adding a Kubernetes control plane. This choice adds provider/network/state/secret operational work. Local Compose supplies repeatable failure tests but cannot establish cloud AZ or PIT recovery.\n\nTradeoffs: authoritative session reads add database latency; a 30-second catalog TTL permits explicitly bounded staleness; refresh races require reauthentication; Mongo remains a shared bottleneck.
